The Graphix Programming Language

Core

print, println, and log produce a null event after processing each message. This acknowledgement lets a seq step advance, including when the same message is printed again. Changing only the destination produces no acknowledgement. If an enclosing expression should produce nothing, end its block with never() explicitly.

/// The result of a three-way comparison.
type Ordering = [`Less, `Equal, `Greater];

/// Equality. `==` and `!=` consult the implementation of the operand
/// type — and of every type nested inside it — falling back to the
/// structural comparison of values where there is none. Outside core
/// only an abstract type may implement it. The methods run inside the
/// comparison, as often as the comparison needs them, so they are
/// `#[pure]`.
trait Eq {
    /// true if the two values are equal
    #[pure]
    val eq: fn(self, other: self) -> bool;
    /// the part of `self` that `eq` reads, which the runtime hashes
    /// (`array::dedup`): two values `eq` calls equal must give equal
    /// parts. An implementation that leaves it out hashes by its
    /// type alone, which is correct but makes `dedup` compare each value
    /// with every other. The runtime calls it, a program never does.
    #[pure]
    val hash: fn(self) -> Any
};

/// Ordering. `<`, `>`, `<=` and `>=` consult the implementation the
/// way `==` consults `Eq`, and so do `array::sort`, `min`/`max` and map
/// keys. `#[pure]`, as `Eq` is.
trait Ord {
    /// the order of `self` relative to `other`
    #[pure]
    val cmp: fn(self, other: self) -> Ordering
};

/// Printing. String interpolation, `print`/`println`, `dbg` and `log`
/// consult the implementation the way `==` consults `Eq`, everywhere
/// in the printed type. `#[pure]`, as `Eq` is.
trait Display {
    /// the printed form of `self`
    #[pure]
    val fmt: fn(self) -> string
};

/// Data. An abstract type crosses data only through its implementation:
/// a cast or a typed read (`json::read`, `pack::read`,
/// `sys::net::subscribe`, ..) makes a value with `from_value`, and a
/// writer (`json::write`, `pack::write`, `sys::net::publish`, ..)
/// writes what `to_value` returns. Only the module that defines the
/// type, where its representation is visible, implements it, and a
/// method it leaves out is the representation itself: `impl Cast for T
/// {}` reads and writes `T` as its representation. Casts and writers
/// call the methods, a program never does, so they are `#[pure]`.
trait Cast {
    /// the data `self` is written as
    #[pure]
    val to_value: fn(self) -> Any;
    /// the value `v` reads as, or why it can't
    #[pure]
    val from_value: fn(v: Any) -> Result<self, `InvalidCast(string)>
};

/// A collection: a type constructor whose values can be traversed and
/// rebuilt — `Array`, `List`, `Map` (over its values), and any type a
/// program implements it for. `self<'a>` is the constructor applied to
/// the element type. `fold`, `filter_map` and `flat_map` are required;
/// the rest derive from them, and an implementation overrides what it
/// can do better. `filter_map`'s callback drops an element by returning
/// null and keeps one by returning it, or `` `Keep(v) `` to keep a `v`
/// that may itself be null, which is how the derived `map` and `filter`
/// keep null elements.
/// `use Collection::*` makes the methods callable bare, and `map(c, f)`
/// then does the same thing whatever `c` is. A parameter typed
/// `Collection` accepts any collection: `|c: Collection| fold(c, ..)`.
trait Collection {
    /// fold the elements, front to back
    val fold: fn(self<'a>, init: 'b, f: fn(acc: 'b, x: 'a) -> 'b throws 'e) -> 'b throws 'e;
    /// the elements `f` maps to a value, in order: null drops one,
    /// `` `Keep(v) `` keeps `v`, null included
    val filter_map: fn(self<'a>, f: fn(x: 'a) -> ['b, null, `Keep('b)] throws 'e) -> self<'b> throws 'e;
    /// the concatenation of `f` over the elements
    val flat_map: fn(self<'a>, f: fn(x: 'a) -> self<'b> throws 'e) -> self<'b> throws 'e;
    /// `f` over every element
    val map: fn(self<'a>, f: fn(x: 'a) -> 'b throws 'e) -> self<'b> throws 'e
        = |c, f| filter_map(c, |x| `Keep(f(x)));
    /// the elements `f` accepts
    val filter: fn(self<'a>, f: fn(x: 'a) -> bool throws 'e) -> self<'a> throws 'e
        = |c, f| filter_map(c, |x| select f(x) { true => `Keep(x), false => null });
    /// the first element `f` accepts
    val find: fn(self<'a>, f: fn(x: 'a) -> bool throws 'e) -> Option<'a> throws 'e
        = |c, f| {
            let init: [`Found('a), null] = null;
            let found = fold(c, init, |acc, x| select acc {
                null as _ => select f(x) { true => `Found(x), false => null },
                found => found
            });
            select found { `Found(x) => x, null as _ => null }
        };
    /// the first value `f` maps an element to
    val find_map: fn(self<'a>, f: fn(x: 'a) -> Option<'b> throws 'e) -> Option<'b> throws 'e
        = |c, f| {
            let init: Option<'b> = null;
            fold(c, init, |acc, x| select acc { null as _ => f(x), found => found })
        };
    /// the number of elements
    val len: fn(self<'a>) -> i64 = |c| fold(c, 0, |n, _| n + 1)
};

impl Collection for Array<'_>;
impl<'k> Collection for Map<'k, '_>;
impl Collection for List<'_>;

/// shift a left by b bits, filling with zeros. The amount b is taken
/// modulo the bit width of the type (a negative b as its two's
/// complement bits), so shl(1, 64) is 1 and shl(1, -1) is i64::MIN
val shl: fn<'a: Int + Singleton>(a: 'a, b: 'a) -> 'a;

/// shift a right by b bits: arithmetic for a signed type (the sign
/// fills, shr(-8, 1) is -4), zero-filling for an unsigned one. The
/// amount b is taken modulo the bit width of the type, as in shl, so

/// when v updates return v if the new value is different from the previous value,
/// otherwise return nothing.
val uniq: fn<'a: Discernible>(v: 'a) -> 'a;

/// when v updates place it's value in an internal fifo queue. when clock updates
/// return the oldest value from the fifo queue. If clock updates and the queue is
/// empty, record the number of clock updates, and produce that number of
/// values from the queue when they are available. When flush updates
/// discard every value waiting in the queue; recorded clock updates are kept.
/// When flush_before updates to n, discard the values waiting that arrived
/// before the n-th v update, the first being the 0-th.
val queue: fn(#clock:Any, ?#flush:Any, ?#flush_before: [i64, null], v: 'a) -> 'a;

/// queuefn wraps a function f and returns a function with the same signature
/// whose invocations are queued and released by an external trigger.
///
/// Each call site of queuefn creates a fresh queue. The wrapper has an
/// internal pop_count initialized to 1, so the first invocation runs
/// immediately. Subsequent invocations push their args onto the queue and
/// emit nothing until #trigger fires; each #trigger update releases one
/// queued invocation, or banks a pop slot if the queue is empty. A fire
/// of #trigger in the cycle the queuefn is born releases nothing. A call
/// site that sleeps keeps its queued calls: no release takes one while it
/// sleeps, and at its wake the slots banked meanwhile release them.
///
/// If #count is provided as a writable ref, the current queue depth is
/// written through it whenever it changes, to a place (`&mut s.depth`)
/// as to a binding: as a level, so a cycle's changes arrive as its final
/// depth. If null (default), depth is not reported. f may not
/// have a variadic argument or a defaulted label: wrap a lambda that
/// calls it.
///
/// When f re-emits, the queue and pop_count are NOT reset. Subsequent
/// pops process queued args with the new f, regardless of which f was
/// current when those args were queued. If you need a fresh queue when f
/// changes, build it explicitly using `queue` instead.
///
/// Concurrent in-flight invocations are possible if #trigger fires before
/// f finishes emitting a previous invocation's output — the wrapper
/// emits whatever any in-flight invocation produces.
val queuefn: fn<'a: Function>(?#count: [&mut i64, null], #trigger:Any, f: 'a) -> 'a;

/// hold the most recent value of v interally until clock updates. If v updates
/// more than once before clock updates, older values of v will be discarded,
/// only the most recent value will be retained. If clock updates when no v is held
/// internall, record the number of times it updated, and pass that many v updates
/// through immediatly when they happen.
val hold: fn(#clock:Any, v: 'a) -> 'a;


/// when v updates, return it, but also print it along
/// with the position of the expression to the specified sink
val dbg: fn(?#dest:[`Stdout, `Stderr, Log], v: 'a) -> 'a;

/// print a log message to stdout, stderr or the specified log level using the rust log
/// crate. Returns null after processing each message.
val log: fn(?#dest:Log, msg: 'a) -> null;

/// print a raw value to stdout, stderr or the specified log level using the rust log
/// crate. Does not automatically insert a newline or add the source module/location.
/// Returns null after processing each message.
val print: fn(?#dest:Log, msg: 'a) -> null;

/// print a raw value to stdout, stderr or the specified log level using the rust log
/// crate followed by a newline. Returns null after processing each message.
val println: fn(?#dest:Log, msg: 'a) -> null;

/// Throttle v so it updates at most every #rate, where rate is a
/// duration (default 0.5 seconds). Intermediate updates that push v
/// over the #rate will be discarded. The most recent update will always
/// be delivered. If the sequence, m0, m1, ..., mN, arrives simultaneously
/// after a period of silence, first m0 will be delivered, then after the rate
/// timer expires mN will be delivered, m1, ..., m(N-1) will be discarded.
val throttle: fn(?#rate:duration, v: 'a) -> 'a;

core::buffer

The buffer submodule provides functions for working with raw bytes: conversion between bytes and strings/arrays, concatenation, and a flexible binary encode/decode system with control over endianness and variable-length encoding.

core::math

The math submodule wraps Rust's f64 math intrinsics (trigonometric, hyperbolic, exponential, logarithmic, power, rounding, comparison, predicate, and angle-conversion routines) plus the standard mathematical constants. Argument and result conventions match std::f64: angles are in radians, NaN propagates through arithmetic, and min/max return the non-NaN operand when one input is NaN.

For polymorphic n-ary min / max / sum / product over Number, use the top-level functions in core instead — the bindings here are the binary f64-only forms.

core::opt

The opt submodule provides combinators for working with optional values — graphix's Option<'a> is just the structural union ['a, null], and these functions mirror the most useful parts of Rust's std::option::Option API in a reactive setting.

The plain combinators (or, and, zip, …) are strict, like && and ||: they produce once every argument has a value, so opt::or(a, b) waits for b even when a is not null. To decide from the first alone, select on it: select a { null => b, v => v }. contains(v, x) is that select already: a null v answers false without waiting for x.

The higher-order combinators (map, flat_map, filter, or_else, ok_or_else, is_some_and, is_none_or) are deliberately fire-and-forget: they never queue inputs. If a callback is slow or never produces a value, a new input simply supersedes the pending one (latest wins). Use the explicit core::queue / core::hold operators when you need ordered async behavior.

use super::Result;
/// true if v is not null
val is_some: fn(v: ['a, null]) -> bool;

/// true if v is null
val is_none: fn(v: ['a, null]) -> bool;

/// true if v is not null and equals x. Produces false when v is null,
/// whatever x is.
val contains: fn<'a: Discernible>(v: ['a, null], x: 'a) -> bool;

/// or_default(v, d): if v is null return d, otherwise return v
val or_default: fn(v: ['a, null], d: 'a) -> 'a;

/// or(a, b): return a if non-null, otherwise return b (which may itself
/// be null).
val or: fn(a: ['a, null], b: ['a, null]) -> ['a, null];

/// and(a, b): return b if a is non-null, otherwise return null.
val and: fn(a: ['a, null], b: ['b, null]) -> ['b, null];

/// xor(a, b): return whichever of a or b is non-null, or null if both
/// or neither are non-null.
val xor: fn(a: ['a, null], b: ['a, null]) -> ['a, null];

/// ok_or(v, e): return v unchanged when non-null, otherwise return
/// error(e).

/// return null.
val zip: fn(a: ['a, null], b: ['b, null]) -> [('a, 'b), null];

/// unzip(p): given a tuple-valued option, return the pair of options.
/// null input yields (null, null).
val unzip: fn(p: [('a, 'b), null]) -> (['a, null], ['b, null]);

/// map(v, f): apply f to the inner value if v is non-null, otherwise
/// return null. It is `select v { null as _ => null, x => f(x) }`, so it
/// fires as f does: f answers every non-null input (a slow async f
/// answers each in order), and fires again whenever what f reads fires.
val map: fn(v: ['a, null], f: fn(x: 'a) -> 'b throws 'e) -> ['b, null] throws 'e;

/// flat_map(v, f): apply f to the inner value if v is non-null,
/// otherwise return null. f's own optional result is forwarded
/// unchanged. It fires as map does.
val flat_map: fn(v: ['a, null], f: fn(x: 'a) -> ['b, null] throws 'e) -> ['b, null] throws 'e;

/// filter(v, pred): if v is non-null and pred(v) is true, emit v.
/// Otherwise (v is null, or pred is false) emit null. It fires as map
/// does.
///
/// Caveat for reactive predicates: when pred takes more than one cycle
/// to produce its bool, the emitted value is the *current* input, not
/// the input pred was actually answering for. If the input changes
/// between feeding pred and pred firing, you'll see the new value
/// gated on a verdict about the old one. Pure predicates (the
/// expected case) are unaffected. Use `core::queue` if you need
/// strict input-bool pairing.
val filter: fn(v: ['a, null], f: fn(x: 'a) -> bool throws 'e) -> ['a, null] throws 'e;

/// or_else(v, f): return v if non-null, otherwise return whatever f()
/// produces. f runs only while v is null, as an arm of
/// `select v { null as _ => f(), x => x }` does: it starts at v's first
/// null, pauses while v is non-null, and resumes at the next null.
val or_else: fn(v: ['a, null], f: fn() -> ['a, null] throws 'e) -> ['a, null] throws 'e;

/// ok_or_else(v, f): return v if non-null, otherwise return
/// error(f()). f runs only while v is null, as for or_else.
val ok_or_else: fn(v: ['a, null], f: fn() -> 'e throws 'x) -> Result<'a, 'e> throws 'x;

/// is_some_and(v, pred): true when v is non-null and pred(v) is true,
/// false when v is null or pred is false. It fires as map does: for a
/// non-null v, no output is produced until pred fires.
val is_some_and: fn(v: ['a, null], f: fn(x: 'a) -> bool throws 'e) -> bool throws 'e;

/// is_none_or(v, pred): true when v is null or pred(v) is true, false
/// when v is non-null and pred is false. It fires as map does: for a
/// non-null v, no output is produced until pred fires.
val is_none_or: fn(v: ['a, null], f: fn(x: 'a) -> bool throws 'e) -> bool throws 'e
